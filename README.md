# Interactive Quiz Application

## Project Description
The Interactive Quiz Application is a web-based system that allows users to participate in online quizzes and view results instantly. The application automates quiz evaluation and follows the MVC architecture for better scalability and maintenance.

## Technologies Used
- Java
- JSP and Servlets
- JavaScript, HTML, CSS
- MySQL
- Apache Tomcat

## Features
- User login and registration
- Timed quizzes
- Automatic answer evaluation
- Real-time score calculation
- Result display

## Applications
- Online examinations
- Educational platforms
- Training and assessment systems
